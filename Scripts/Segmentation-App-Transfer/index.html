      Help

      Reference tips for drawing, editing, navigation, and export.

      Drawing
      • Polygon: click to add points, then click near the first vertex to close.
      • Curve: while drawing a polygon, toggle Curve, click a bend/control point, then click the next vertex.
      • Dragged or duplicated shapes auto-fit inside the image bounds before export.
      • Ellipse: click once to set center, move cursor to size, click again to place.
      • Rectangle: click once for corner one, move cursor, click again for opposite corner.
      Editing
      • Use Tab (next) and Shift+Tab (previous) to cycle through annotations.
      • Vertex edit mode: click and drag a vertex to move it.
      • Select a shape, then use the Color picker in the selected-shape controls to set its display color.
      • Alt + click on a polygon edge to insert a new vertex.
      • In Edit mode, hold Shift or Ctrl/Cmd, then drag a selection box. Shift adds and Ctrl/Cmd subtracts.
      • Press Delete/Backspace to remove selected annotation or vertices.
      Navigation
      • Mouse wheel to zoom. Middle-click drag to pan.
      • Press ? to open/close this Help modal.
      Export
      • Export JSON saves annotations and the original image. Export Mask saves a binary PNG. Invert Mask flips foreground/background values.
      • Open JSON restores annotations and its embedded image. For annotation-only JSON, load the matching PNG separately.
      Keyboard Shortcuts
      • Ctrl/Cmd + ZUndo last action
      • Ctrl/Cmd + Shift + ZRedo last undone action
      • TabSelect next annotation
      • Shift + TabSelect previous annotation
      • Ctrl/Cmd + DDuplicate selected shape
      • Delete / BackspaceDelete selected annotation or vertices
      • CToggle curved next polygon edge while drawing
      • Alt + ClickInsert a vertex on nearest polygon edge
      • Shift + dragIn Edit mode: add vertices to marquee selection
      • Ctrl/Cmd + dragIn Edit mode: subtract vertices from marquee selection
      • Mouse wheelZoom at cursor
      • Middle mouse dragPan view temporarily
      • ?Open/close this Help modal
      • EscCancel active drawing (tool stays active); also closes open dialogs

      Remove image from batch?

      This permanently removes the selected images, their saved annotations, and any unfinished annotation drafts from this browser batch. Original files and downloaded exports are not affected. Export first to keep completed annotations; unfinished drafts are not exported.

      Reusable class catalog

      Save class names and IDs for use across images in this browser. Export and import a catalog to share it or keep a backup.

      Class names are case-sensitive. Register each polygon label before exporting COCO with the catalog enabled. LLNL JSON and binary masks keep their existing formats.

      Annotation quality review

      Checks cover crossing or overlapping polygon edges, invalid geometry, zero-area shapes, regions smaller than 4 original-image pixels², and duplicate boundaries. Warnings do not change shapes or prevent intentional exceptions.

      Crossing strands can overlap intentionally. Ellipse overlap estimates use a sampled boundary.
